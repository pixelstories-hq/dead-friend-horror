# Dead Friend Horror

This is a very short horror game I created with PS Maker: https://pixelstories.io. It is my first time making a horror game and I had a lot of fun with the horror art/atmosphere and sound design!

It's super short. When I timed myself, it only took 4 minutes to get the "win" ending.

There are two endings, one where you die and one where you escape.

If you die or get stuck, you have to restart the game (exit and reopen).
